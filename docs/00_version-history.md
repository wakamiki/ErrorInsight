# Version History

## バージョン表記ルール

ErrorInsight では、バージョンを `00.00.00` 形式で表記する。

```text
major.minor.patch
```

### major

一番左の数字。
製品段階や大きな方針変更を表す。

- `01.00.00`: 無料版 Version 1
- `02.00.00`: 有料版 Version 2

### minor

中央の数字。
大きめの機能追加や段階的な到達点を表す。

- 重要な機能追加をしたときは、必ず右から3桁目である中央の数字を1つ上げる
- `00.50.00`: Version 0.5
- `01.50.00`: Version 1 の中間的な機能追加

### patch

一番右の数字。
小さな修正や軽微な改善を表す。

- 表記修正
- 小さなバグ修正
- ドキュメント追記
- 既存機能の軽微な改善

## バージョン運用方針

- 小さな変更では一番右の数字を増やす
- 重要な機能追加では必ず中央の数字を増やす
- 例: `00.00.00` から重要な機能追加をした場合は `00.01.00` にする
- 段階的な区切りでも中央の数字を増やす
- 大きな方針変更や製品段階の変更では一番左の数字を増やす
- Public repository では無料版 Version 1 までを扱う
- 有料版 Version 2 は Private repository で扱う

| `00.50.00` | 無料版途中段階 | CLI起動、クリップボード取得、エラー行抽出の途中段階 |
| `00.60.00` | 無料版途中段階 | エラー行から見て取れる範囲の簡易説明、原因候補、確認ポイント表示 |
| `00.70.00` | 無料版途中段階 | JavaScript / SQL の代表的なエラーを無料版対象に追加 |
| `00.80.00` | 無料版途中段階 | 言語種別表示、ヒント表示、日本語ラベルの表示幅調整 |
| `01.00.00` | 無料版完成 | クリップボード取得、エラー行抽出、行番号付き表示、簡易分析表示、エラーなし表示 |
| `02.00.00` | 有料版 | 複雑な詳細分析、課金、ライセンス認証などを Private repository で扱う |
