# 10 リリースノート

## `01.00.00` 無料版完成

### 概要

ErrorInsight無料版を `01.00.00` として完成版扱いにする。

無料版では、クリップボード内の複数行ログからエラーらしい行を抽出し、Python / Java / C# / JavaScript / SQL の代表的なエラーについて、エラー行から見て取れる範囲で簡易説明、原因候補、確認ポイント、ヒントをCLI上に表示する。

### 主な機能

- クリップボードからログ文字列を取得する
- エラーらしい行を行番号付きで抽出する
- Python / Java / C# / JavaScript / SQL の言語ヒントをスコア方式で判定する
- エラー種別ごとの簡易説明を表示する
- 原因候補と確認ポイントを表示する
- エラー本文から読み取れる型名、属性名、変数名などをヒントとして表示する
- 日本語ラベルの表示幅を揃えて読みやすく表示する
- エラー行がない場合は、そのことを日本語で表示する
- 起動時に `動作モード: ローカル実行` と `外部通信: なし` を表示する

### 対象外

- クリップボード以外からの入力
- 複雑な原因推測
- 修正コードの自動生成
- GUI
- 外部AI API連携
- 課金処理
- ライセンス認証
