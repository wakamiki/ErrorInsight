# External Design

## 利用シーン

- コーディング作業中にエラーが発生した時
- 長いログの中から読むべきエラー行を素早く見つけたい時

## CLIの起動方法

無料版では、インストール済みのCLIコマンドとして起動できることを目指す。

```bash
errorinsight
```

短縮コマンドとして、以下でも起動できる。

```bash
ei
```

ログをコピーしたあとにコマンド文字列をコピーすると、クリップボード内のログが上書きされる可能性がある。
そのため、実用時は `ei` を手入力するか、ターミナル履歴から実行する。

## 入力方法

1. ユーザーがターミナルやコンソールに表示されたログをコピーする
2. ErrorInsight がクリップボードからログ文字列を取得する

## 表示内容

- 抽出したエラー行
- 元ログ上の行番号
- エラー種別ごとの簡易説明
- 判定に使った言語種別
- エラー行から見て取れる範囲の原因候補
- よくある確認ポイント
- エラー本文から読み取れる追加ヒント
- 判断できない場合の「不明」表示
- エラー行が見つからない場合のメッセージ

### 出力形式

抽出したエラー行ごとに、元ログ上の行番号、エラー行、言語種別、簡易説明、原因候補、確認ポイントを表示する。
ヒントを抽出できる場合は、確認ポイントとは別にヒント行を表示する。
日本語の表示が読みやすくなるように、ラベルの開始位置を揃える。

```text
2行目       : AttributeError: 'NoneType' object has no attribute 'split'
言語        : Python
説明        : 存在しない機能や値を使おうとした可能性があります。
原因候補    : メソッド名や属性名の間違い、None参照、型違いの可能性があります。
確認ポイント: 対象オブジェクトの型、属性名・メソッド名、Noneになっていないかを確認してください。
ヒント      : 対象の型は 'NoneType'、存在しない属性またはメソッド名は 'split' です。型と属性名・メソッド名を確認してください。
```

エラー行が見つからない場合は、以下のように表示する。

```text
エラーらしい行は見つかりませんでした。
```

## 有料版への導線

無料版では、エラー行から見て取れる範囲の簡易的な原因候補と確認ポイントまでを表示する。
有料版では、ログ全体の文脈、ソースコード、実行環境、外部AI APIなどを使った、より詳しい調査支援機能を提供する予定。
ただし、有料版の具体的な分析内容や内部仕様は Public repository には記載しない。

## 正常系の動き

1. ユーザーがCLIで `errorinsight` または `ei` を実行する
2. ErrorInsight がログをコピーして Enter を押すよう案内する
3. ユーザーがエラーログをクリップボードにコピーして Enter を押す
4. ErrorInsight がクリップボード内の複数行ログを取得する
5. ログを1行ずつ確認する
6. エラーらしいキーワードを含む行を抽出する
7. 抽出したエラー行から、簡易説明、原因候補、確認ポイントを作る
8. 抽出結果と簡易分析結果をコンソールに表示する
9. 次のログをコピーして Enter を押すと、続けて解析できる
10. コンソールを閉じるか、`q` を入力して Enter を押すと終了する

## 異常系の動き

### クリップボードが空の場合

- ログが取得できないことを表示する
- 次の入力待ちに戻る

### エラーらしい行が見つからない場合

- エラー行が見つからなかったことを表示する
- 次の入力待ちに戻る

### 原因候補を判断できない場合

- エラー行は表示する
- 原因候補は「不明」と表示する
- 無理に断定しない

### クリップボードの取得に失敗した場合

- クリップボードを読み取れなかったことを表示する
- 次の入力待ちに戻る

## ユーザー操作の流れ

1. 開発中にエラーが発生する
2. ターミナルで `errorinsight` または `ei` を実行する
3. ターミナルやコンソールに表示されたログをコピーして Enter を押す
4. 抽出されたエラー行を確認する
5. 表示された簡易説明、原因候補、確認ポイントを確認する
6. ヒントが表示された場合は、型名、属性名、変数名などの具体情報を確認する
7. 表示された行番号とエラー行をもとに、修正箇所を調べる
8. 続けて使う場合は、新しいログをコピーして Enter を押す
9. 終了する場合は、コンソールを閉じるか、`q` を入力して Enter を押す
