# ErrorInsight 操作説明書

## 概要

ErrorInsight は、クリップボード内のエラーログを解析し、
原因候補や確認ポイントを表示するローカルCLIツールです。

本ツールはローカル環境のみで動作し、
外部ネットワーク通信は行いません。

---

## 配布方針

ErrorInsight は、初心者でも使いやすい形での配布を予定しています。

公開時には、Pythonを直接操作しなくても使えるように、
ZIPを解凍して起動できる形式を目指します。

---

## 動作確認環境

現在の開発環境は以下です。

- Windows
- Python 3.13
- PowerShell

※ 現在は開発中のため、実行にはPython環境が必要です。
※ 公開時には初心者向けの起動手順を整備する予定です。

---

## 起動時表示

起動時には以下のメッセージが表示されます。

```txt
ErrorInsight
動作モード: ローカル実行
外部通信: なし
```

これは、本ツールがローカル専用で動作し、
ネットワーク通信を行わないことを示しています。

---

## 基本的な使い方

1. `Start_ErrorInsight.bat` を起動する
2. エラーログをコピーする
3. Enter を押して分析結果を確認する
4. 続けて使う場合は、新しいログをコピーして Enter を押す
5. 終了する場合はコンソールを閉じるか、`q` を入力して Enter を押す

一度起動すると、画面を閉じるまで何度でも続けて使えます。
PC終了後、PC再起動後、コンソールを閉じた後、または `q` + Enter で終了した後に使う場合は、もう一度 `Start_ErrorInsight.bat` を起動します。

※ すでにPowerShellやターミナルを開いている場合は、新しく開き直す必要はありません。


実行キーワード:

```bash
errorinsight
```

または

```bash
ei
```


4. 分析結果を確認する

## 注意事項

* すべてのエラーを完全に解析できるわけではありません
* 推定結果は補助情報として利用してください
