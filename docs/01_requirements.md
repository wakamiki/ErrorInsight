# Requirements

## システム名

ErrorInsight
(Pythonエラーログ分析整理ツール)

## 目的

Python / Java / C# のエラーログから怪しいエラー行を抽出し、原因候補を確認しやすくする。
あわせて、Python・CLIアプリ開発・設計分離の学習を目的とする。

## 背景

学習や開発中に発生するエラーログは、そのままでは見づらく、
原因が分かりづらい。
そのため、ログからエラー情報を抽出し、原因候補とあわせて確認できるツールを作成する。

## v1スコープ

### v1の主目的

1段階目：クリップボード内のJava / C# / Python のログから、よくあるエラー文を高速に拾いエラー文のみをコンソールに表示する
2段階目：拾ったエラー文を例外名・エラーキーワードに基づいて分析し、原因候補を推測表示する

### v1の段階

#### v0.5 エラー行抽出

- クリップボードから複数行ログを取得できる
- エラーらしいキーワードを含む行を抽出できる
- 抽出した行をCLI上に表示できる

#### v1 分析推測表示

- 抽出したエラー行ごとに原因候補を表示できる
- Python / Java / C# の代表的なエラーに対応する
- 判断できない場合は、無理に断定せず不明として表示する
- v1では、例外名・エラーキーワードに基づいて原因候補を推測表示する
- 外部AI API連携は将来拡張として扱う

### v1でできること

- クリップボード内の複数行を取得できる
- エラーらしいキーワードを含む行を抽出できる
- 抽出した行をコンソールに表示する
- 例外名・エラーキーワードに基づいて原因候補を推測表示する
- 分析した結果をエラー行ごとにコンソールに表示する

### v1でやらないこと

- クリップボード以外からのログ文字列の取得
- Java/C#/Python以外のエラー文対応
- 言語ごとの切り替え機能
- エラー文ハイライト表示
- エラー件数集計
- エラー傾向分析 

### v1で扱うログの前提

- 複数行のテキストログを対象とする
- 入力された文字列を1行ずつ確認する
- 大文字・小文字の違いは区別せずに判定する

### v1の判定ルール

* error
* exception
* traceback
* failed
* fatal
* nullpointerexception
* nullreferenceexception
* valueerror
* typeerror
* nameerror
* indexerror
* keyerror
* importerror
* zerodivisionerror
* illegalargumentexception
* numberformatexception
* indexoutofboundsexception
* indexoutofrangeexception
* filenotfoundexception
* ioexception
* invalidoperationexception

### v1の分析推測ルール

- 抽出したエラー行に含まれる例外名やキーワードをもとに、原因候補を表示する
- 判断できない場合は、不明として表示する
- 原因候補は断定せず、「可能性がある」という表現にする
- 外部AI API連携はv1では必須にしない


### v1の出力形式

- 抽出した行をコンソールに表示する
- 可能であれば元ログ上の行番号も表示する
- 該当行がない場合は、見つからなかったことを表示する

### v1の完了条件

- クリップボードにコピーした複数行ログを読み込める
- Java / C# / Python の代表的なエラー行を抽出できる
- 抽出したエラー行を元ログの行番号付きで表示できる
- 抽出したエラー行ごとに原因候補を表示できる
- 原因が推測できない場合は、不明として表示できる
- エラー行が見つからない場合は、そのことを表示できる
- 開発中にログをコピーして実行するだけで、読むべき箇所を絞り込める


## 対象ユーザー

- 開発者本人
- ログを手早く確認したい人

## 入力
- クリップボードから入力

## 出力
- コンソール表示

## 機能要件

- ログ複数行を読み込めること
- エラーを含む行を抽出できること
- 軽量で開発画面を邪魔せず手早く使えること
- 抽出結果と分析推測結果をCLI上に表示できること

## 非機能要件

- CLIで動作すること
- Pythonで実装すること
- 処理が理解しやすい構成であること

## やらないこと

- グラフ表示
- GUI化
- データベース保存
