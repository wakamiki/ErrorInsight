# Requirements

## システム名

ErrorInsight
(エラーログ抽出CLIツール)

## 目的

Python / Java / C# / JavaScript / SQL のエラーログから怪しいエラー行を抽出し、エラー行から見て取れる範囲で原因候補や確認ポイントを確認しやすくする。
あわせて、Python・CLIアプリ開発・設計分離・テスト作成の学習を目的とする。

## 背景

学習や開発中に発生するエラーログは、そのままでは見づらく、読むべき箇所が分かりづらい。
そのため、ログからエラーらしい行を抽出し、行番号付きで確認できるツールを作成する。
さらに、代表的なエラーについては、エラー行そのものから判断できる範囲で簡易説明、原因候補、確認ポイントを表示する。

## 利用者方針

ErrorInsight は、日本語話者の初学者・学習中エンジニア・個人開発者を主な対象とする。
英語の長いエラーログを読む前に、まず見るべき行と確認ポイントを日本語で把握できるようにする。

### 対象ユーザー

- 日本語話者の初学者
- 英語のエラーログを読むことに慣れていない学習者
- 個人開発中にログの読むべき箇所を素早く見つけたい人
- Python / Java / C# / JavaScript / SQL の代表的なエラーを日本語で確認したい人

### 対象外ユーザー

- 英語UIや多言語対応を必要とするユーザー
- 高度な自動診断や修正コード生成を期待するユーザー
- 企業向けの監視、ログ保存、分析基盤として使いたいユーザー

## 無料版スコープ

### 無料版の主目的

クリップボード内の Python / Java / C# / JavaScript / SQL のログから、よくあるエラー文を高速に拾い、エラー行と簡易的な原因候補をCLI上に表示する。

### 無料版でできること

- クリップボード内の複数行ログを取得できる
- エラーらしいキーワードを含む行を抽出できる
- 抽出した行をCLI上に表示できる
- 元ログ上の行番号を表示できる
- 判定に使った言語種別を表示できる
- 抽出したエラー行ごとに原因候補を表示できる
- Python / Java / C# / JavaScript / SQL の代表的なエラーに対する原因候補を表示できる
- 判断できない場合は「不明」と表示できる
- よくある確認ポイントを表示できる
- エラー本文から型名、属性名、変数名などが読み取れる場合はヒントを表示できる
- エラー種別ごとの簡易説明を表示できる
- 原因候補を含めた読みやすい出力形式で表示できる
- エラー行が見つからない場合に、そのことを表示できる

### 無料版でやらないこと

- クリップボード以外からのログ文字列の取得
- エラー行から見て取れない複雑な原因推測
- コード全体や実行環境を踏まえた診断
- 修正コードの自動生成
- Python / Java / C# / JavaScript / SQL 以外のエラー文対応
- 言語ごとの切り替え機能
- エラー文ハイライト表示
- エラー件数集計
- エラー傾向分析
- GUI化
- データベース保存
- 外部AI API連携
- 課金処理
- ライセンス認証

## 有料版について

有料版では、無料版の簡易分析を超えた、より詳しい調査支援機能を提供する予定。
有料版の詳細仕様と実装は Private repository で管理する。

## 配布方針

無料版は、既存の日本語ブログサイトを主な入口として紹介する。
GitHubを使ったことがない一般の日本語話者にも届きやすいように、ブログ側では使い方、安全性、できること、できないことを日本語で説明する。

### 配布導線

1. 既存ブログサイトに ErrorInsight の紹介記事を作成する
2. ブログ記事から無料版の入手方法へ案内する
3. GitHub はコード公開、更新履歴、信頼性確認の場所として使う
4. 初期配布は GitHub Releases を想定する
5. 完成度が上がった段階で PyPI / pipx による配布を検討する
6. 一般ユーザー向けの利便性が必要になった段階で Windows 用実行ファイル配布を検討する

### 配布時に重視すること

- 日本語で説明する
- 怪しいソフトに見えないよう、何をするツールかを明確にする
- 何をしないツールかを明確にする
- クリップボード内容の扱いを明記する
- 外部送信しないことを明記する
- 履歴保存やファイル保存をしないことを明記する
- ソースコードを公開していることを明記する

### 安全性の説明方針

無料版では、クリップボード内のテキストをローカルで読み取り、エラーらしい行と簡易分析結果を表示する。
外部API送信、履歴保存、ファイル保存、課金処理、ライセンス認証は行わない。

## 無料版で扱うログの前提

- 複数行のテキストログを対象とする
- 入力された文字列を1行ずつ確認する
- 大文字・小文字の違いは区別せずに判定する

## 無料版の分析範囲

- エラー行に含まれる例外名やキーワードから判断できる範囲に限定する
- ログ全体に含まれる言語特有の文言から、言語種別を推定する
- 言語種別の推定では、単一キーワードだけで即決せず、強いヒントと弱いヒントを点数化して判定する
- 一定以上の根拠がない場合は、無理に言語を断定せず「不明」とする
- 代表的なエラー種別に対して、定型的な簡易説明を表示する
- 代表的なエラー種別に対して、定型的な原因候補を表示する
- 代表的なエラー種別に対して、よくある確認ポイントを表示する
- エラー本文から読み取れる具体情報は、ヒントとして表示する
- 判断できない場合は、無理に断定せず「不明」と表示する
- ログ全体の文脈、ソースコード、実行環境、外部AI APIを使った複雑な推測は行わない

## 無料版の出力形式

- 抽出した行をCLI上に表示する
- 元ログ上の行番号を表示する
- 判定に使った言語種別を表示する
- エラー種別ごとの簡易説明を表示する
- 原因候補を表示する
- よくある確認ポイントを表示する
- ヒントがある場合は、確認ポイントとは別にヒントを表示する
- 日本語ラベルの読み始め位置を揃えて表示する
- 判断できない場合は「不明」と表示する
- 該当行がない場合は、見つからなかったことを表示する

- クリップボードにコピーした複数行ログを読み込める
- Python / Java / C# / JavaScript / SQL の代表的なエラー行を抽出できる
- 抽出したエラー行を元ログの行番号付きで表示できる
- 抽出したエラー行ごとに、エラー行から見て取れる範囲の原因候補を表示できる
- Python / Java / C# / JavaScript / SQL の代表的なエラーについて、簡易説明と確認ポイントを表示できる
- 判定に使った言語種別を表示できる
- ヒントを抽出できるエラーについて、確認ポイントとは別にヒントを表示できる
- 判断できないエラーについては「不明」と表示できる
- エラー行が見つからない場合は、そのことを表示できる
