
## 検出キーワードの考え方

Java / C# / Python に共通しやすいキーワードを優先する。

例：

* error
* exception
* traceback
* failed
* fatal
* nullpointerexception
* nullreferenceexception
* valueerror
* typeerror
* nameerror
* indexerror
* keyerror
* importerror
* zerodivisionerror
* illegalargumentexception
* numberformatexception
* indexoutofboundsexception
* indexoutofrangeexception
* filenotfoundexception
* ioexception
* invalidoperationexception

キーワードは後から調整できるよう、処理の中に直接散らばらせないこと。
