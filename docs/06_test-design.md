# 06 テスト設計書

## 目的

ErrorInsight無料版の主要機能について、どの観点でテストするかを整理する。

本書では具体的なテストケースではなく、確認すべき機能・条件・異常系・境界値を定義する。

---

## テスト観点一覧

| 観点ID | テスト観点 | 対象 |
|---|---|---|
| TD-001 | 起動メッセージ | `presenter.py`, `cli.py` |
| TD-002 | クリップボード取得 | `cli.py` |
| TD-003 | 入力チェック | `cli.py` |
| TD-004 | エラー行抽出 | `extractor.py` |
| TD-005 | 言語スコア計算 | `language_detector.py` |

## TD-001 起動メッセージ

### 確認内容

- 起動時にツール名が表示される
- ローカル実行であることが表示される
- ネットワーク通信しないことが表示される

### 確認対象

- `format_startup_message`

---

## TD-002 クリップボード取得

### 確認内容

- クリップボードからログ本文を取得できる
- 取得したログ本文を後続処理へ渡せる
- クリップボード読み取り失敗時にエラーメッセージを表示できる

### 確認対象

- `cli.py`

### 備考

クリップボード取得は環境依存があるため、基本は手動テストで確認する。

---

## TD-003 入力チェック

### 確認内容

- クリップボードが空の場合、処理を中断できる
- 空白のみの場合、処理を中断できる
- 通常の日本語文章の場合、エラーなしとして扱える
- 小文字化済みログを判定用に作成できる

### 確認対象

- `cli.py`
- `format_clipboard_empty_message`
- `format_no_error_lines_message`

---

## TD-004 エラー行抽出

### 確認内容

- `error` を含む行を抽出できる
- `exception` を含む行を抽出できる
- `traceback` を含む行を抽出できる
- 大文字・小文字を区別せず抽出できる
- 行番号を保持できる
- 抽出後も元の行文字列を保持できる

### 確認対象

- `extract_error_lines`

---

## TD-005 言語スコア計算

### 確認内容

- 強いヒント一致時に `+5` できる
- 弱いヒント一致時に `+1` できる
- 組み合わせヒント一致時に `+3` できる
- 複数ヒントが一致した場合、合計点を計算できる
- 言語ごとに個別のスコアを保持できる

### 確認対象

- `calculate_language_scores`

---

## TD-006 言語判定

### 確認内容

- 最大スコアが `0` の場合は「不明」になる
- 最大スコアが `1` または `2` の場合は「不明」になる
- 最大スコアが `3` 以上で単独最高点の場合、対象言語を返す
- 最大スコアが同点の場合は「不明」になる
- Java と JavaScript を誤判定しにくいこと

### 確認対象

- `decide_language_hint`
- `detect_language_hint`

---

## TD-007 簡易分析

### 確認内容

- 抽出したエラー行を分析できる
- 言語ヒントを使って該当言語のルールを優先できる
- 代表的なエラーに対して簡易説明を返せる
- 原因候補を返せる
- 確認ポイントを返せる
- 判定できないエラーを「不明」として扱える

### 確認対象

- `analyze_error_lines`

---

## TD-008 結果表示

### 確認内容

- 行番号を表示できる
- エラー行を表示できる
- 推定言語を表示できる
- 簡易説明を表示できる
- 原因候補を表示できる
- 確認ポイントを表示できる
- 複数エラー行を読みやすく表示できる
- エラー行がない場合のメッセージを表示できる

### 確認対象

- `format_result`
- `format_no_error_lines_message`

---

## TD-009 異常系メッセージ

### 確認内容

- クリップボードが空の場合のメッセージを表示できる
- クリップボード読み取り失敗時のメッセージを表示できる
- エラー行が見つからない場合のメッセージを表示できる

### 確認対象

- `format_clipboard_empty_message`
- `format_clipboard_read_error_message`
- `format_no_error_lines_message`

---

## TD-010 手動実行確認

### 確認内容

- 実際にCLIを起動できる
- `errorinsight` コマンドで実行できる
- `ei` コマンドで実行できる
- Python / Java / C# / JavaScript / SQL の代表ログで動作する
- 通常文ではエラーなしとして扱える
- 起動から結果表示までの流れが自然である

### 確認対象

- CLI全体

---

## テスト優先度

| 優先度 | 対象 |
|---|---|
| 高 | 起動、入力チェック、エラー行抽出、言語判定、結果表示 |
| 中 | 簡易分析、異常系メッセージ、境界値 |
| 低 | CLIインストール状態、環境依存の表示差異 |

---

## 自動テストと手動テストの切り分け

| 種別 | 対象 |
|---|---|
| 自動テスト | `extractor.py`, `language_detector.py`, `analyzer.py`, `presenter.py` |
| 手動テスト | クリップボード取得、CLI起動、コマンド登録状態、実行環境依存の表示 |
