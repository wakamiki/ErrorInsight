- `template.format(**match.groupdict())` は、正規表現で抜き出した名前付きの値をヒント文に埋め込む処理である

- `any(...)` のように `if` と `for` が連結した書き方は、英語の語順に近く感じて理解に時間がかかる
- `wcwidth` と `wcswidth` の使い分けがややこしく、単文字と文字列で使う関数が違う点が分かりづらかった
- 表示形式を変えると、実装だけでなくテストの期待値も一緒に更新する必要があった

### 学び

- `wcwidth` は1文字の表示幅を確認するための関数で、複数文字の文字列には `wcswidth` を使う
- ターミナルでは、見た目の文字幅を考慮しないと、日本語と英数字が混ざったときに位置がずれやすい
- 分析結果の `hint` は、確認ポイントに混ぜるよりも、独立した行として表示した方が読みやすい
- 表示処理を変えたときは、手動テストだけでなく `tests/test_presenter.py` の期待値も更新する必要がある
- `pytest` が通る状態まで戻すと、表示変更後も安心して次の作業に進める

### 改善点

- `if` 文、`for` 文、`if` と `for` を組み合わせた書き方を重点的に復習する
- 機能はかなり形になってきたため、次は想定外の表記にならないようにテストケースを増やす
- ヒント表示のあるケース、ヒント表示のないケース、判断できないケースを分けて確認する
