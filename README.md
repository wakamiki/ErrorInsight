# ErrorInsight

## 概要

ErrorInsight は、コンソールに貼り付けたログ文字列から、エラーの可能性がある行を抽出する CLI ツールです。

初期バージョンでは、ログ解析を高度に自動化するのではなく、事前に定義したキーワードをもとに怪しい行を検出することを目的とします。

## 目的

このプロジェクトは、Python と CLI 開発の学習を目的とした開発プロジェクトです。

単に動くコードを作るだけでなく、以下の観点を重視します。

- 要件定義から実装までの開発プロセスを理解する
- 入力、分析、表示の責務を分離する
- 保守しやすい構成を考える
- 小さい単位で実装と確認を進める
- テスト観点を整理してから動作確認する

## 対象範囲

### v1 で扱うこと

- コンソールからログ文字列を受け取る
- ログを行単位で扱う
- エラー関連キーワードを含む行を抽出する
- 抽出結果をコンソールに表示する

### v1 で扱わないこと

- GUI の作成
- ファイル入力
- AI によるログ分析
- 外部 API 連携
- API キーを使う機能
- 複雑な設定ファイル管理

## 想定キーワード

初期段階では、以下のようなキーワードを検出対象として想定します。

- `error`
- `exception`
- `traceback`
- `failed`
- `fatal`
- `valueerror`
- `typeerror`
- `filenotfoundexception`

キーワードの追加や調整は、実装に直接埋め込まず、将来変更しやすい形を意識します。
